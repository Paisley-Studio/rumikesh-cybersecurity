# Rumikesh Cybersecurity — Cinematic Intro

A 32-second, 1920×1080 / 30fps brand intro built entirely in code with [Remotion](https://www.remotion.dev).
GitHub Actions renders it. No video files are stored in this repo, and the soundtrack is generated by a script.

## Storyboard

| Time | Scene |
| --- | --- |
| 0.0–2.1s | Hooded operator at a curved 3-monitor SOC desk, holographic security panels floating around (letterbox opening) |
| 2.1–3.6s | Close-up on the live threat consoles, a glass **ENC** file rotating, shields and locks flying past |
| 3.6–5.5s | Pull back: a helix of data and icons spirals around the operator, then a whip-zoom |
| 5.3–6.5s | Brand-coloured vortex transition |
| 6.3–11.2s | A storm of tumbling folders and files. An energy core grows and absorbs them into particles, then a flash |
| 10.9–13.9s | A comet carves through a star field |
| 13.7–16.8s | Warp speed with glass PEM / LOG / PCAP / CVE assets flying past |
| 16.6–18.9s | A wall of glass security modules (FIREWALL, SIEM, EDR, ZTNA…) with light-cross flicker |
| 18.7–21.3s | Fly-through of a tunnel of modules and live dashboards |
| 21.1–23.5s | Hero glass vault folder opens and turns |
| 23.3–26.7s | Rows of live security dashboards pan past, then a rush zoom |
| 26.4–32.0s | Particles assemble the **Rumikesh** emblem, then the wordmark, tagline and URL on a reflective, foggy floor |

## Render on GitHub

1. Push this folder to a GitHub repository.
2. Open **Actions → Render Rumikesh intro → Run workflow**.
3. Choose the logo variant (`pink` or `blue`), the tagline, the URL and the quality.
4. When the run finishes, download `rumikesh-intro-*.mp4` from the run's **Artifacts** section.

Every push to `main` that touches `src/`, `public/`, `scripts/` or `package.json` also triggers a render with the default settings.

## Preview locally (optional)

```console

```

## Customise

- **Text and colours:** `src/Root.tsx` holds the defaults: `theme`, `tagline`, `url` and `music`.
- **Brand palettes:** `src/theme.ts` (`pink` uses `#FF1E8C`, `blue` uses `#1E9BFF`).
- **Scene timings:** the `T` table in `src/Main.tsx`.
- **Sound design:** `scripts/generate-audio.mjs`. Its cue times match the timeline.
- **Logo assets:** the `public/*-emblem.png`, `*-word.png` and `*-tag.png` files were keyed from the supplied logo images.
